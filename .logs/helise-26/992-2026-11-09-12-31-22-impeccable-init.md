# Impeccable-init

## 2026-11-09 kl. 12:31 — Helise-26

### Oppgave
Helene vil gjøre UX-designet på nytt med Impeccable (pbakaus/impeccable) i stedet for BMad-UX, blant annet for å prøve og sammenligne arbeidsflyten i kurset. Første steg var å installere Impeccable og kjøre `init`, som lager produktgrunnlaget (PRODUCT.md).

### Plan
- Installerte Impeccable på prosjektnivå for Claude Code med det offisielle installasjonsprogrammet (`npx impeccable install --providers=claude --scope=project -y`).
- Kjørte `/impeccable init`: leste PRD, arkitektur og den gamle UX-mappa, og stilte tre spørsmål om omfang, grunn og bekreftelse av produktsammendraget.
- Skrev PRODUCT.md i prosjektroten ut fra PRD-en og svarene.

### Resultat
- Installert: `.claude/skills/impeccable/` (skill, referanser og en Windows-binær, impeccable-motoren v0.1.19, ca. 23 MB) og `.claude/agents/impeccable-*.md` (fire subagenter). Hooks for designdetektoren ligger i `.claude/settings.local.json`, som er git-ignorert og dermed bare lokal. De virker først når Claude Code startes på nytt.
- Svar fra Helene:
  - full redesign; det gamle utseendet («Warm Editorial» + «Rich Mocha») er bare bakgrunnsmateriale, mens skjermer, flyter og PRD-krav gjelder fortsatt;
  - grunnen er å lære og prøve Impeccable;
  - produktsammendraget er bekreftet.
- Ny `PRODUCT.md` i roten dekker brukere (Student og sensor), formål, posisjonering («viser arbeidet, finner aldri på»), bruksflyt, krav og grenser, stemme, tilgjengelig materiale, prinsipper og WCAG 2.2 AA. Ingen DESIGN.md er skrevet ennå; den lages i neste steg (new-work).
- Ikke aktuelt: bildegenerering er ikke tilgjengelig, så buildPath-spørsmålet ble hoppet over (code-first). Det finnes ingen kjørbar app ennå, så live-modus ble ikke satt opp.
- PRODUCT.md og Impeccable-filene er ikke committet.

### Åpne punkter
- Bestem om `.claude/skills/impeccable/` og `.claude/agents/` skal committes (sensor ser verktøyene) og om Windows-binæren på ca. 23 MB under `scripts/bin/` skal git-ignoreres.
- Neste UX-steg med Impeccable: velg første flate (forslag: Søknad med Refleksjonsnotat) og kjør `/impeccable shape` eller vanlig new-work, som også lager ny DESIGN.md.
- Når ny DESIGN.md finnes: oppdater PRD §0 og andre lenker som peker på den gamle UX-mappa (ux-JobAssistant-2026-09-11) som UX-autoritet.
