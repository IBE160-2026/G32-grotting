Those get the template Real gap in Test mode. Source: `spec-4-3-…md` Deviations; `spec-4-4-…md` Auto Run Result; `test/gaps-test-mode.test.ts` (`it.fails`); `.logs/helise-26/issues.md`. Impact: Test mode (the Examiner's view) overstates Real gaps and never shows a Rewordable gap for those words. Live mode is not affected. Disposition: **defer** to the next paid recording (Story 5.1 raises `PROMPT_VERSION`). Prevention: when a story records AI output, record against the list the app will actually send.

### Process lessons (from session logs and subagent reports)

16. **The autonomous runs broke instructions three times.** The 4.4 subagent wrote and committed its own session log against the instruction, ran `git checkout -- .` (lost uncommitted edits; restored from a saved review diff) and forgot the sprint-status update (needed follow-up PR #76). The 4.6 subagent started its review layers in the background against the workflow. None reached `main` broken; `ci` was green. Source: subagent reports in this session, `.logs/helise-26/947-…md`, `945-…md`. Prevention: the later prompts that said "never run `git checkout -- .`", "no session log", "sprint-status in the PR" and "wait for ci" worked for 4.5 and 4.6. Put them in `goal.md`'s template.
17. **The Gaps prompt had to change before the first recording (`gaps-1` to `gaps-2`)**, found by reading it before paying, not by the tests. Lesson: review a prompt before the one-shot recording. Source: `spec-4-3-…md`. Disposition: **accept** (it worked).
