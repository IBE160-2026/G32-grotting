# AI notice: manual checks (FR-24)

Story 3.6 (FR-24, NFR-2, AD-13, AD-16, UX-DR17, UX-DR38). The automated tests prove that the notice opens before phase 1 with focus on its title, that «Avbryt» and Esc keep every input and send nothing, that «Godta og fortsett» saves `noticeVersion` and starts phase 1 once, that it is not asked again in the session, that Test mode never shows it, and that it has no serious axe finding at 1280 px and 360 px (`e2e/ai-notice.spec.ts`, `src/modules/ai/ui/*.test.ts`, `src/shared/ui/components/dialog.test.ts`). What only a person can judge is recorded here. **A row is a result only when the Date, Tester and Result columns are filled in. A blank Result means open, not passed.**

How to run rows 2 to 5: the notice is never shown in Test mode, so start the app with live settings and a **made-up** key, which is refused by the provider (phase 1 is code only; the Letter request of Story 3.7 goes out after phase 1 and fails with a made-up key, which shows the section alert and costs nothing): `AI_PROVIDER=openrouter AI_MODEL=anthropic/claude-sonnet-5.5 AI_API_KEY=not-a-real-key npm run dev`. Use a fresh tab: the acceptance lives in that tab's session storage.
